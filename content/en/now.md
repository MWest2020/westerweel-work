This overview writes itself. Every project keeps its roadmap as data in its
own repository: the goal, the phases, and what "done" means for the current
phase, each item with evidence (a PR, issue or document). An agent factory on
my own hardware (Ratatoskr and Habitat) reads that every two hours and puts it
here, with the changes in the making right now. An item only counts as done
with evidence. Nothing sensitive is on this page: no secrets, no document
content, no links into private repositories.
