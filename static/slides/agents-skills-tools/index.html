The toddler and the cookie jar

Give it a goal (the cookie) and capabilities (a chair, a sibling), and it will use them.

System prompt + question + web search tool = mission + capabilities.

It is not misbehaving. It reaches the goal with whatever you left within reach.

Childproofing the kitchen

  • *What is within reach, the agent harness:* which skills and tools, with which permissions (read, write, execute).
  • *The house rules, hygiene:* least privilege, segmentation, secrets management, logging.

You do not make the toddler less curious. You decide what is in the kitchen.

A conductor, not an orchestra

SREna is a local coordinator on a MacBook. Hub and spoke: it hands work to sub-agents.

Other agents plug in via MCP, so SREna does not own their code.

Each capability stays with whoever builds it.

When the cloud goes quiet

  • *Sovereignty:* when an AI vendor is down, SREs can still troubleshoot, just not with that vendor's service. A local agent keeps helping.
  • *Cost:* a power-user tier is about $500 a month, $6,000 a year: roughly the extra cost of a capable laptop.
  • *Trend:* local models keep improving.

A local model is a second engine, not a replacement for the first.

The apprentice and the handbook

The agent → skill → tool pattern.

The handbook is the knowledge base, and every source in it is labelled gold, silver or bronze.

The apprentice is only as good as the book it learns from.

Hallmarks on every answer

  • *Gold:* confirmed by a human
  • *Silver:* from a source
  • *Bronze:* purely AI-generated

Chatting with an agent is L1: you are the loop. SREna suggests gold and a human promotes it: L2.

How far do you let the golem walk?

  • *L0 Manual:* only monitoring is automated
  • *L1 Assisted:* the golem investigates, the human acts
  • *L2 Partial:* the golem proposes, a human approves
  • *L3 High:* the golem acts alone on bounded actions
  • *L4 Full:* the golem directs itself

The golem of Prague did exactly what it was told. The question is how long you leave the room.
