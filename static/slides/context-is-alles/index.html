Context is alles

Over de kennisbank als het eigenlijke verschil

Van een hub voor infra-repo's naar een SRE-agent die volledig lokaal draait.

Het klonk als tien keer gedaan

De procedure stond er al. De agent had die niet opgezocht.

Niemand kon herleiden waar het antwoord vandaan kwam.

Context(management) is alles

Het model had de verkeerde context, of eigenlijk geen context.

Het antwoord is een MCP

Die laad je in, en die stuurt de agent naar de kennisbank. Een sessie start in de hub, de coördinator voor een stuk of tien infra-repo's.

Wat ze samen regelen

Een agent die zijn eigen kooi mag aanpassen, zit niet in een kooi.

Sindsdien

Verzint een agent zo'n procedure nauwelijks nog.

Niet omdat het model beter werd, maar omdat de context dat werd.

Thuis: hetzelfde patroon

De agent begint bij de kennisbank en blijft binnen grenzen die hij zelf niet kan verschuiven.

SREna: volledig lokaal

Logs, incidenten en runbooks: precies de context die je het minst graag de deur uit stuurt.

Eerlijk: de evaluatiefase

Nog geen gebruikers. Het lokale model haalt de cloud-baseline nog niet.

De modelkeuze valt in het eerste kwartaal van 2027.

Goud, zilver, brons

Wat als goud staat, weegt zwaarder, en ze zegt eerlijk waar haar antwoord vandaan komt.

Het idee is geleend van Google SRE.

Een eerlijke spiegel

Een klein model vult gaten ook op, maar slechter. Daardoor zie je ze.

Wat een lokaal model je leert

Zonder baseline is elke indruk een gevoel.

De grootste les

De kennisbank gaat hallucineren tegen, niet het model.

Soevereiniteit

Wie de context bezit, kan het model vervangen.

De context gaat gewoon mee.

Context is everything

On the knowledge base as the real difference

From a hub for infra repos to an SRE agent that runs entirely locally.

It sounded done ten times

The procedure was already there. The agent had not looked it up.

Nobody could trace where the answer came from.

Context (management) is everything

The model had the wrong context, or really no context at all.

The answer is an MCP

You load it, and it sends the agent to the knowledge base. A session starts in the hub, the coordinator for ten or so infra repos.

What they take care of together

An agent that can modify its own cage is not in a cage.

Since then

An agent hardly ever makes up such a procedure.

Not because the model got better, but because the context did.

At home: the same pattern

The agent starts at the knowledge base and stays within boundaries it cannot move itself.

SREna: entirely local

Logs, incidents and runbooks: exactly the context you least want to send out the door.

Honest: the evaluation phase

No users yet. The local model does not reach the cloud baseline yet.

The model choice will be made in the first quarter of 2027.

Gold, silver, bronze

What is marked as gold weighs more, and she is honest about where her answer comes from.

The idea is borrowed from Google SRE.

An honest mirror

A small model fills gaps too, but worse. That is what makes them visible.

What a local model teaches you

Without a baseline, every impression is a feeling.

The biggest lesson

The knowledge base is what prevents hallucination, not the model.

Sovereignty

Whoever owns the context can replace the model.

The context simply comes along.

Context (management) is everything
